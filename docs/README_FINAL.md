# SalesPro - Complete Documentation

## Overview
SalesPro is a modern CRM and sales management platform.

## Key Features
- ✅ Complete CRM
- ✅ Sales Pipeline
- ✅ Analytics & AI
- ✅ Gamification
- ✅ Real-time collaboration

## Getting Started
1. Install: `npm install`
2. Configure: Copy `.env.example` to `.env`
3. Migrate: `npx supabase db push`
4. Run: `npm run dev`
